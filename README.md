# 跟媽媽說的話

這個資料夾專門放我想跟媽媽說、或已經跟媽媽說過的話。
一則一個檔案，放在 `說/` 裡面，純文字，隨時可以用任何編輯器打開。

## 怎麼記

最快的方式，在這個資料夾裡執行：

    python 說.py 媽媽，今天我去了正覺寺

會自動建立 `說/20260907_1430.md`，狀態預設是「想說」。

已經說出口的（在心裡、在靈前、在夢裡、在寺裡），加 `--已說`：

    python 說.py --已說 --在 靈前 媽媽，今天我去了正覺寺

不帶任何參數執行，會列出所有紀錄並重建 `索引.md`：

    python 說.py

也可以完全不用腳本，直接把 `_範本.md` 複製到 `說/` 裡改名、填寫。

## 一則的長相

    日期：2026-06-06
    狀態：已說
    在：夢裡

    媽媽！你在那個世界要好好的喔！

前三行是欄位，空一行之後全部是要說的話，想寫多長都可以。
「狀態」只有兩種：想說、已說。
「在」是選填，記下是在哪裡說的：心裡、靈前、夢裡、寺裡、或任何地方。

## 命名

`說/YYYYMMDD_HHMM.md`，用時間當檔名，一天可以記很多則。
如果想給某一則一個標題，可以改成 `說/20260606_你在那個世界要好好的.md`，腳本一樣認得。

## 從「想說」變「已說」

打開那個檔案，把「狀態：想說」改成「狀態：已說」，補上「在：」就好。
