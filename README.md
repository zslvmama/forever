# 關於媽媽

媽媽叫徐阿秀。這個資料夾放所有關於她的記錄：她是誰、她的事、我跟她說的話、我夢到她。
一則一個檔案，純文字，隨時可以用任何編輯器打開。

這裡的東西是這樣來的：我用說的，AI 幫我整理成文字、放進對的檔案、推上 GitHub。沒有程式，沒有指令。

## 裡面有什麼

    媽媽是誰.md              基本資料、家人、安放的地方
    媽媽的事.md              她的一生，我記得的她
    說/                      初一十五跟她說的話，一則一檔
    夢/                      夢到她，一次一檔
    索引.md                  說/ 的時間軸
    給讀到這裡的人.md        給未來打開這裡的人或 AI
    To-whoever-reads-this.md 同上，英文版
    影片與照片               不放在這裡，都在 YouTube 頻道 @zslvmama，話裡會給連結

## 一則「說的話」的長相

    說的日期：2026-09-25（農曆八月十五）

    媽媽，那天是農曆八月初二，社區發展協會提前慶祝中秋節，
    眾人一同烤肉，很歡慶，很有趣，媽媽你也看看哦。

第一行是跟她說的那天，都是農曆初一或十五，在神主前說；空一行之後是說的話。特別的場合，例如去八德看媽媽，會寫在話裡。
給媽媽看的照片和影片都放上 YouTube 頻道 @zslvmama，照片會先做成短片；話裡只給連結，這裡只有文字。
檔名是 `說/日期_標題.md`，日期是事情發生的那天，不是說的那天。

## 一個夢的長相

`夢/日期_作夢.txt`，日期是入夢那天，第一人稱，第一句寫時間。

## 怎麼補

跟 AI 說就好：想跟媽媽說的話、想起的事、夢到的。AI 整理後放進對的檔案，索引一起更新，然後推上 GitHub。
