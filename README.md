# 關於媽媽

媽媽叫徐阿秀。這個資料夾放所有關於她的記錄：她是誰、她的事、我跟她說的話、我夢到她。
一則一個檔案，純文字，隨時可以用任何編輯器打開。

## 裡面有什麼

    媽媽是誰.md          基本資料、家人、安放的地方
    媽媽的事.md          她的一生，我記得的她
    說/                  初一十五跟她說的話，一則一檔
    夢/                  夢到她，一次一檔
    索引.md              說/ 的時間軸，腳本自動產生
    給讀到這裡的人.md    給未來打開這裡的人或 AI
    To-whoever-reads-this.md  同上，英文版
    說.py、_範本.md      記「說/」用的工具
    照片                 檔名是拍攝時間，紀錄裡會指到它

## 記一則「說的話」

在這個資料夾裡執行：

    python 說.py 媽媽，今天我去了正覺寺

會自動建立 `說/20260907_1430.md`，狀態預設是「想說」。
已經說出口的，加 `--已說`，可以加 `--在` 記在哪裡說的：

    python 說.py --已說 --在 靈前 媽媽，今天我去了正覺寺

不帶參數執行，會列出所有紀錄並重建 `索引.md`。
也可以不用腳本，把 `_範本.md` 複製到 `說/` 裡改名、填寫。

一則的長相：

    日期：2026-09-07
    狀態：已說
    在：靈前

    媽，你看，那株移栽的芒果樹，如今都快兩層樓高了。

前三行是欄位，空一行之後是要說的話。「狀態」只有想說、已說兩種。
「在」選填：心裡、靈前、夢裡、寺裡，或任何地方。
說出口了，就把「想說」改成「已說」，補上「在」。

## 記一個夢

直接在 `夢/` 新增 `YYYYMMDD_作夢.txt`，日期是入夢那天，第一人稱，第一句寫時間。

## 補《媽媽的事》或《媽媽是誰》

直接改那個檔案。想起什麼就補上，不用管順序。
